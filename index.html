Main findings

Test-time training (TTT) improves success on several tasks, and memory swaps show that stored context can affect target selection in tested block-return trials. Failures remain on other tasks. We are investigating whether relevant information is lost during execution, is not retrieved, or fails to influence action generation.

With 45 training demonstrations per task (plus five held out), adding TTT raises ten-task test success from 6.5% to 38.1% (+31.6 percentage points). Both models train for 20,000 updates on the same demonstrations and are evaluated on the same 100 test seeds per task. The largest gains are in block ordering, rearrangement, and return.

Selected runs with more demonstrations achieve higher success

In runs with 45 versus 195 training demonstrations per task, validation success increases from 30% to 85% on block swapping, from 80% to 100% on block return, and from 0% to 40% on multi-block return. Each rate uses 20 validation episodes. At 495 training demonstrations, T-block swapping reaches 80/100 test successes. Task mixtures also differ across these runs, so this does not isolate the effect of demonstration count. Uncovering blocks in color order remains at 1/20 validation successes with 195 training demonstrations, despite successful covering in all 20 episodes.

Training shapes a policy’s dependence on memory

With 195 training demonstrations per task, retaining memory during training and evaluation outperforms resetting it at every policy call on block return (100% vs. 35%) and multi-block return (40% vs. 0%). In the earlier 16-step, 6,000-update block-ordering study, resetting memory only during evaluation reduces success from 26% to 0%, while a policy trained and evaluated with resets achieves 30%. Clearing memory can break a learned strategy even when the task can be solved without retaining it.

Memory can guide decisions, but its use varies across settings

An earlier block-return model succeeds in all eight original trials. Holding its weights and current observation fixed, swapping in another episode’s memory redirects the block toward that episode’s starting mat in all eight memory-swap trials. This demonstrates a causal influence of memory content on the return target.

For the ten-task model on observe_and_pickup, a decoder identifies the target from memory recorded just after viewing with 85% accuracy on held-out scenes. Yet at the first decision after hiding, swapping in memory of a different target changes object choice in 0% of paired tests (148 pairs), with all other inputs and sampling noise fixed. The probe and intervention occur at different times. We have not yet determined whether target information is lost between these points or remains available but fails to influence actions.

The 45-versus-195 demonstration comparisons use 20 validation episodes per task; the 495-demo T-block result above uses 100 test episodes. The ten-task comparison currently reports one trained model per condition; stability across training seeds remains to be measured.

Task descriptions and experiment settings

The 45-, 195-, and 495-demo runs train jointly on 10, 4, and 2 tasks, respectively. All counts are per task. Each run reserves five demonstrations and trains for 20,000 updates, with 32 action steps executed per policy call. The 45-demo models use the same training episodes, normalizer, and evaluation seeds. Evaluation splits and task groups differ, so these columns do not isolate the effect of adding demonstrations. “—” means no result is available in that column.

Early cue encoding and later target choice need to be tested together

This diagnostic uses the evaluated ten-task B3 policy and 292 scenes. The scenes are split into 175 for training the decoder, 43 for validation, and 74 for held-out testing. The decoder identifies the target from memory recorded immediately after the cue with 85.0% held-out accuracy (95% CI: 81.9–87.9%), compared with 24.1% when the cue is absent.

At the first decision after the target is hidden, we swap memory formed from different target cues while holding the current image, robot state, positional state, and action noise fixed. The selected object changes in 0/148 held-out pairs.

Scaling the memory branch’s output by factors of 2 or 5 on the 43 validation scenes does not meet the predefined criteria for improved cue following. With a factor of 5, the fraction of reaches classified as too short rises to 67.5%. Neither setting proceeds to held-out testing. The decoding result is measured immediately after the cue, whereas the memory swap is tested at a later decision. These results do not establish that target information survives until that decision. We will measure decoding, readout changes, and action responses at the same decision point to distinguish loss of information from failures to use it.
